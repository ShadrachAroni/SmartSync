┌─────────────────────────────────────────────────────────────────────────────┐
│                         RESISTOR USAGE SUMMARY                              │
└─────────────────────────────────────────────────────────────────────────────┘

3 × 330Ω Resistors:
  ✓ RGB LED: Red, Green, Blue cathodes (3 resistors)
  ✓ Green LEDs: 3 LEDs × 1 resistor each = 3 resistors
  ✓ Active Buzzer: Optional 1 resistor
  ✓ MOSFET Gate: 1 resistor (330Ω or 100Ω)
  Total: 7-8 resistors needed (you have 3, may need more or reuse)

3 × 10kΩ Resistors:
  ✓ DHT22: 1 pull-up resistor (DAT to 3.3V)
  ✓ SRF05: 2 resistors for voltage divider (ECHO protection)
  ✓ MOSFET: 1 pull-down resistor (Gate to Ground)
  Total: 4 resistors needed (you have 3, may need 1 more or adjust)


┌─────────────────────────────────────────────────────────────────────────────┐
│                         WIRE TYPE USAGE GUIDE                               │
└─────────────────────────────────────────────────────────────────────────────┘

M-M (Male-to-Male):
  • ESP32 pins → Breadboard
  • Breadboard power rails
  • Ground connections
  • Resistor connections
  • LED connections
  • Buzzer connections

F-M (Female-to-Male):
  • DHT22 sensor (if it has male pins)
  • PIR sensor (male pins)
  • Ultrasonic sensor (male pins)
  • RTC module (male pins)
  • LCD I2C adapter (if it has male pins)

F-F (Female-to-Female):
  • 12V adapter to fan connections
  • 12V adapter ground to breadboard ground
  • Extending wires for remote components
